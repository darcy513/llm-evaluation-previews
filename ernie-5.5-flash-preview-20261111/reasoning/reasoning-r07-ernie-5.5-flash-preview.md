# 推理过程

**首先确定规律：**

题目说"将单词中的全部字母重新排列后，**恰好**能得到**一个**不同的常见英文单词"。关键词是"恰好一个"。

**验证符合规律的词（恰好一个变位词）：**
- dad → add（仅1个）✓
- dab → bad（仅1个）✓
- gut → tug（仅1个）✓
- low → owl（仅1个）✓
- cat → act（仅1个）✓

**验证不符合规律的词：**
- ear → are, era（有**2个**，超过一个）✗
- cop → 无变位词（**0个**）✗
- ego → 无常见变位词（0个）✗
- mom → 无变位词（0个）✗
- ate → eat, tea, eta（有**多个**）✗

所以规律是：**重排字母后恰好能得到唯一一个不同的常见英文单词**（既不能是0个，也不能是2个及以上）。

**逐项检验选项：**

| 选项 | 字母重排 | 变位词数量 | 是否符合 |
|------|----------|-----------|---------|
| A. leg | gel | 1个 | ✓ 符合 |
| B. dam | mad | 1个 | ✓ 符合 |
| C. rat | **tar, art** | **2个** | ✗ 不符合 |
| D. car | arc | 1个 | ✓ 符合 |
| E. bin | nib | 1个 | ✓ 符合 |

**rat** 重排后既能得到 **tar** 又能得到 **art**，共两个不同的常见单词，不满足"恰好一个"的条件。

最终答案：C
