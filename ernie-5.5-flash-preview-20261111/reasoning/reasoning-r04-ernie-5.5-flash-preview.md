# 设置问题

设三枚硬币为 $X_1, X_2, X_3$，每枚出现正面（H）的边际概率为 $1/3$，出现反面（T）的概率为 $2/3$。

**关键约束：** 每次实验中反面数量一定是偶数。三枚硬币的反面数只能是 0、1、2、3，其中偶数只有 **0 或 2**。

因此只有以下四种结果可能出现：

| 结果 | 反面数 | 概率 |
|------|--------|------|
| HHH | 0 | $p_0$ |
| HTT | 2 | $p_1$ |
| THT | 2 | $p_2$ |
| TTH | 2 | $p_3$ |

其余结果概率为 0。

# 建立方程

**概率归一化：**
$$p_0 + p_1 + p_2 + p_3 = 1$$

**各硬币正面边际概率为 1/3：**

- 硬币 1 为正面：HHH、HTT → $p_0 + p_1 = \tfrac{1}{3}$
- 硬币 2 为正面：HHH、THT → $p_0 + p_2 = \tfrac{1}{3}$
- 硬币 3 为正面：HHH、TTH → $p_0 + p_3 = \tfrac{1}{3}$

# 求解

将三个边际方程相加：
$$3p_0 + (p_1 + p_2 + p_3) = 1$$

代入归一化条件 $p_1 + p_2 + p_3 = 1 - p_0$：
$$3p_0 + (1 - p_0) = 1 \implies 2p_0 = 0 \implies p_0 = 0$$

# 直观验证（期望法）

由期望的线性性（**与是否独立无关**），反面总数的期望为：
$$E[\text{反面数}] = 3 \times \frac{2}{3} = 2$$

但反面数只能取 0 或 2。设 $P(0) = q_0$，$P(2) = q_2$，则：
$$q_0 + q_2 = 1, \qquad 0\cdot q_0 + 2\cdot q_2 = 2$$

解得 $q_2 = 1,\ q_0 = 0$。即反面数**必然恰好为 2**，所以 HHH（0 个反面）永远不会出现。

两种方法结论一致。

最终答案：0
