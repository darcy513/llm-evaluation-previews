# 3D 双时区腕表（Dual-Time 3D Watch）

一个完全在浏览器中运行的实时 3D 腕表动画：腕表按当前时间走时，秒针平滑扫动，
同时支持两个 IANA 时区（主表盘 + 6 点位 24 小时小表盘），并在 3D 表盘上显示
日期、星期以及第二时区的 AM/PM。

## 功能

- 完整 3D 腕表：不锈钢表壳、表圈、表冠、表耳、链带、蓝宝石玻璃表镜、3D 时标与指针
- 真实时间驱动，秒针/分针/时针均连续平滑转动（不是每秒跳针）
- 主表盘（TZ1）：12 小时制时、分、秒三针
- 第二时区（TZ2）：6 点位 24 小时小表盘，含 24H 时针、分针与独立小秒针
- 日期 + 星期：3D 表盘左右两个日期窗口分别显示 TZ1 / TZ2；TZ2 窗口同时显示 AM/PM
- 时区切换：常用时区下拉框 + 全部 IANA 时区，自动显示 UTC 偏移与夏令时偏移
- 交互：拖拽旋转视角、滚轮缩放、双击/按钮复位、自动缓慢旋转
- 无外部网络依赖：Three.js 已本地化到 `vendor/three.min.js`，所有贴图由 Canvas 生成
- 项目附 `preview.png` 运行截图，便于快速确认效果

## 运行方式

### 方式一：直接打开（最简单）

用现代浏览器（Chrome / Edge / Firefox / Safari 较新版本）直接打开：

```text
index.html
```

因为脚本以普通 `<script>` 标签加载，不需要 HTTP 服务器，也没有任何网络请求。

### 方式二：本地静态服务器（推荐用于开发调试）

```bash
cd 3d-watch
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/>。

也可以直接执行：

```bash
cd 3d-watch
./run.sh
```

`run.sh` 会启动 `python3 -m http.server` 并尝试打开浏览器（macOS 上会调用 `open`）。

## 测试说明

### 自动验证（已执行）

开发过程中已通过以下方式验证：

1. `node --check app.js`：语法检查通过。
2. `node -e "new Function(...three.min.js...)"`：Three.js 文件可解析。
3. Headless Chrome（CDP）加载页面：
   - 页面无 JavaScript 异常，`#status` 显示“3D 双时区腕表已启动”
   - 主/第二时区数字时钟与日期均正常
   - 时区切换后（TZ1 → UTC，TZ2 → America/New_York）时间与
     `UTC+00:00` / `UTC-04:00` 偏移正确
   - 秒针角度随真实时间连续变化
   - 页面截图成功生成（约 300 KB，画面含腕表与 UI）

### 手动验收清单

1. 打开页面，确认主表盘时、分、秒针连续走动，秒针无跳针、无回跳。
2. 对照系统时间，确认主表盘时间一致（可打开系统时钟秒表对照 1 分钟）。
3. 将 TZ1 切换为 `UTC`，主表盘时间应变为 UTC 时间；将 TZ2 切换为
   `America/New_York`，6 点位小表盘应显示纽约时间（24 小时制），
   其日期窗口的 AM/PM 也应随纽约本地时间正确切换。
4. 观察 3D 日期窗口：日期、星期随所选时区显示；跨日时自动刷新。
5. 拖拽、缩放、双击复位、自动旋转均正常。
6. 完全断网后重新打开 `index.html`，页面仍应正常工作（无 CDN 依赖）。

### 常见问题

- **页面空白 / 提示无法创建 WebGL**：浏览器或系统禁用了硬件加速。
  可在 Chrome 地址栏输入 `chrome://settings/system`，开启“使用图形加速”。
  某些远程桌面/虚拟机环境可改用 Firefox 或安装 SwiftShader。
- **字体显示为英文**：日期窗口与品牌文字使用通用无衬线字体，中文系统与
  英文系统均可正常显示。
- **日期窗口城市名过长**：长名称会被截断并添加省略号，不影响走时。

## 技术要点

- Three.js r160（UMD 全局构建）
- `Intl.DateTimeFormat` + `Intl.supportedValuesOf('timeZone')` 处理时区
- 墙钟时间缓存 200ms 刷新，配合毫秒增量插值，保证秒针连续且缓存刷新不回跳
- 指针采用 `ExtrudeGeometry` 3D 造型，绕 Z 轴以真实时钟角速度旋转
- Canvas 纹理生成表盘、24H 小表盘与日期窗口贴图，无外部图片资源
- PMREM 环境反射 + 方向光阴影 + ACES 色调映射
