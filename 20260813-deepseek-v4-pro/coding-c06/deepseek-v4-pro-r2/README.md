# 弓箭射击模拟游戏

一个单页 Canvas 弓箭射击游戏：场上有 **4 个固定靶子**，玩家拉弓蓄力射出箭矢。
**从第一支箭射出开始计时，到最后一个靶子被命中结束**；用时越短，排行榜名次越高。

## 功能

- 4 个固定靶位（每次开局位置一致，保证排行榜公平）
- 鼠标 / 触屏：移动瞄准，按住拉弓蓄力，松开射箭
- 重力弹道与虚线轨迹预览
- 实时显示：用时、命中数、箭数、蓄力条
- 通关弹窗：显示用时与射箭数，输入昵称保存成绩
- 本地排行榜：按用时升序保留前 10 名（用时相同先比箭数，再比昵称）
- 命中粒子、音效、得分高亮等反馈

## 运行方式

### 方式一：直接打开（最简单）

用浏览器直接打开 `index.html` 即可游玩。

### 方式二：本地 HTTP 服务器（推荐）

```bash
cd archery-game
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/>。

> 排行榜保存在浏览器 `localStorage` 中；若浏览器处于无痕/隐私模式且禁用本地存储，
> 成绩仅在当前会话有效，页面会给出提示。

## 玩法

1. 移动鼠标（或手指）瞄准，虚线为预计飞行轨迹。
2. **按住鼠标左键 / 长按触屏**拉弓，蓄力条越满箭速越快。
3. **松开按键**射出箭矢；箭矢受重力影响，瞄准远处或高处目标时需适当抬高准星。
4. 命中全部 4 个靶子即完成，计时自动停止并弹出成绩保存窗口。
5. 排行榜：用时越短排名越高；页面右上角可随时查看、清空排行榜。

## 测试说明

项目将纯逻辑（物理步进、碰撞、计时通关、排行榜排序/持久化）从 DOM 中解耦，
可在 Node.js 中直接运行单元测试：

```bash
cd archery-game
node --test tests/game.test.js
# 或使用 npm 脚本
npm test
```

测试覆盖：

| 项目 | 说明 |
| --- | --- |
| 靶子配置 | 恰好 4 个靶子，且都在画面与地面范围内 |
| 状态初始化 | 4 个未命中靶子、计时未开始 |
| 弹道计算 | 零/满蓄力速度、蓄力值钳制 |
| 命中判定 | 箭矢进入靶环后命中并停止、记录插靶箭矢 |
| 落地判定 | 箭矢落地后停止 |
| 通关判定 | 4 个靶子全中且计时已开始才判定完成；未射箭不误判 |
| 可通关性 | 对四个靶子分别搜索可行瞄准点与蓄力值，保证全部可命中 |
| 排行榜排序 | 用时升序、只保留前 10 名、更快成绩名次更靠前 |
| 排行榜持久化 | localStorage 存取往返一致、损坏存储不抛异常 |
| 昵称清洗 | 空昵称回退为“玩家”、长度限制 |

预期结果：`pass 14 / fail 0`。

### 手动冒烟测试清单

1. 打开页面，确认左上角显示 `用时 0.00 s / 命中 0 / 4 / 箭数 0`。
2. 按住鼠标，确认蓄力条增长、弓弦后拉、出现虚线轨迹。
3. 松开鼠标，确认箭数 +1 且计时开始走动。
4. 命中任一靶子，确认该靶变暗、出现命中标记与粒子，命中数 +1。
5. 命中全部 4 个靶子，确认计时停止并弹出成绩窗口。
6. 输入昵称保存，打开排行榜确认名次按用时从短到长排列。
7. 刷新页面后重新打开排行榜，确认成绩仍然存在（localStorage 生效时）。
8. 点击“新一局”，确认靶子、箭数、计时全部复位。
